ROME 2026 iPHONE APP

This folder is a Progressive Web App (PWA).
To install on iPhone it must be served over HTTPS (not opened from the Files app as file://).

Once hosted:
1. Open the live URL in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Open ROME 2026 from the Home Screen.

The app includes its own manifest, service worker, local images, icons, itinerary and 82 places.
